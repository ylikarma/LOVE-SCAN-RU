# LOVE SCAN · Рентген-кабинет чувств

Русская версия просмотрщика результатов OOC: снимок привязанности NPC к PC в разрезе поверхности и глубины. Доли компонентов становятся формой 3D-образца, а пульс — его сердцебиением.

Оригинал (корейский): https://yuuuulll35.github.io/love-scan/ — автор @gimyunseul92364.

## Как пользоваться
1. Скопируйте OOC ① и отправьте в чат с ботом, затем скопируйте ответ ИИ и нажмите «Вставить ответ».
2. То же с OOC ② и OOC ③ (в том же чате).
3. Нажмите «Начать сканирование».

## Публикация на GitHub Pages
Загрузите все файлы в репозиторий (с папками `js` и `assets`), затем Settings → Pages → Branch: `main`, папка `/ (root)`.

Сборка не нужна — чистые HTML/CSS/JavaScript.
